워크플로 1 · Claude + JNUclass

강의 덱 — 교안에서 JNUclass까지

결과물은 HTML 파일 하나입니다. 슬라이드, 슬라이드마다의 낭독, 섹션 요약 영상, 안에서 채점되는 연습 문제가 함께 들어 있습니다. 학생은 JNUclass에서 이 파일을 열어 공부합니다.

역할로 보기

단계를 누르면 자세한 내용이 열립니다. 역할을 고르면 그 역할이 맡는 단계만 진하게 보입니다.

  1. 01 입력 모으기교안 · 교재 PDF · 교사용 지도서 교수
    • 교안(docx): 지난해에 쓴 수업 순서와 문장 — 덱의 뼈대가 된다.
    • 교재 PDF: 지면을 잘라 슬라이드에 넣는다. 글자 층이 없으면 그림으로 바꿔 눈으로 읽는다.
    • 교사용 지도서: 정답과 듣기 대본은 여기서만 가져온다.
    원문이 없으면 지어내지 않는다. 자리표시자를 두고 교수에게 요청한다.
  2. 02 규칙 — 스킬 문서AI가 매번 먼저 읽는 규칙을 교수가 쓰고 고친다 교수
    • 인용 원칙: 교재 본문·듣기 대본·정답은 사용자가 준 원문만 쓴다.
    • 영어가 위, 한국어가 아래. 한국어는 번역이 아니라 해설.
    • 한 장에 한 호흡. 섹션마다 교재 지면이 먼저, 해설은 그다음.
    • 모든 슬라이드에 강의 노트(진행 지시 · 시간 · 학생이 틀리는 곳).
    • 연습은 슬라이드 안에서 푼다 — 고르기 · 쓰기 · 짚기 · 나누기.
    english-lecture-deck/SKILL.mdreferences/deck-planning.mdreferences/bilingual-voice.mdreferences/slide-grammar.md

    학기 중에 고친다. 예: 2026-09-22 「덱 제목은 교재의 절 제목 그대로」, 09-23 「대본 인용에는 문장 단위 번역」.

  3. 03 지면 자르기교재 PDF에서 상자·문항 영역만 코드

    좌표표에 따라 잘라 그림 데이터로 저장한다. 휴대폰으로 찍은 지면은 기울기를 바로잡아 넣는다.

    crop_pages.pyfix_p90.pypages_b64.json
  4. 04 덱 조립슬라이드 한 장 = 함수 호출 한 번 AI코드

    AI가 본문(영어 강의체 + 한국어 해설 + 노트)을 조립 스크립트로 쓰고, 라이브러리가 화면을 만든다. 고칠 때는 스크립트를 고치고 다시 조립한다.

    build_4_1.pydeck_lib.pydeck_template_ELS1.html

    한 차시 기준 45–60장. 4주차 4-1은 51장, 4-2는 66장(영상 슬라이드 포함).

  5. 05 소리 — 낭독과 듣기 트랙슬라이드마다 낭독 하나 · 듣기 트랙은 TTS 대체 음원 코드
    • L 키로 그 슬라이드의 영어 문장을 읽는다. 표지·섹션 표지·영상 슬라이드에는 없다. 정답은 상자를 연 뒤 이어 읽는다.
    • 듣기 트랙은 교재 원음이 아니라 지도서 대본을 음성 합성으로 읽힌 것 — 화면에 「TTS 대체 음원」으로 밝힌다.
    narrate.pymake_audio.py*_낭독대본.txt

    6주차 6-1(영어읽기와 쓰기 1): 낭독 58개, 24분 40초.

  6. 06 섹션 요약 영상대본 → TTS → 덱 화면 + 영·한 자막 → mp4 AI코드교수
    • 3주차: 섹션 PDF를 제미나이 노트북에 넣어 만든 영상의 소리만 살려 덱 화면으로 다시 그렸다.
    • 4주차부터: AI가 대본을 쓰고 교수가 검토 → 음성 합성 → 덱 화면을 찍어 자막과 함께 렌더.
    • 자습 주간(6주차)에는 정답이 든 영상을 섹션 끝에 둔다. 개요 영상(정답 없음)만 표지 다음.
    vid/secvid.pyvid/v61_s00.py …video/*.mp4 · *.srt
  7. 07 검증눈으로 보지 않은 덱은 넘기지 않는다 코드교수

    브라우저가 덱을 열어 직접 센다: 넘친 슬라이드, 노트 없는 슬라이드, 연습 문제 채점 동작, 낭독 이어 읽기, 인쇄 때 조작 단추 숨김, PDF 쪽수 = 슬라이드 수. 교수는 전체를 8장씩 묶은 화면으로 훑는다.

    verify.pyshots/*_sheet*.png

    6주차 영어읽기와 쓰기 1: 넘침 0 · 노트 누락 0 · PDF 58쪽·53쪽 = 슬라이드 수.

  8. 08 LMS판영상까지 파일 안에 넣은 HTML 하나 코드

    영상이 옆 폴더에 있으면 JNUclass에서 재생되지 않는다. 그래서 영상(540p)과 서체를 파일 안에 넣은 판을 따로 만든다. 학생 모드로 열리고(점수 표시, 노트 숨김), 교수 모드는 주소 뒤 ?teacher 또는 S 키.

    EMBED=1 STUDENT_DEFAULT=1*_LMS.html

    6주차 영어듣기와 말하기 1 LMS판: 16.7 MB · 16.4 MB. 20 MB를 넘으면 전송이 막혔다.

  9. 09 게시JNUclass 주차 모듈: 덱 → 과제 → 과제 해설 교수코드

    교수가 직접 올리거나, AI가 Canvas API로 올린다. 학생에게 보이는 일은 교수가 설정을 확인한 뒤에만 하고, 로그인은 교수가 직접 한다.

    기존 항목은 지우지 않는다. 비공개로 돌리고 알린다.
