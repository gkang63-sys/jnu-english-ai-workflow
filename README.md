# 교양영어 AI 워크플로 (Claude + JNUclass)

제주대학교 영어영문학과 교양영어 두 과목(영어읽기와 쓰기 1 · 영어듣기와 말하기 1)에서 2026-2학기에 쓴 두 워크플로를 정리한 정적 웹 페이지입니다. 2026-10-16 「AI 시대 인재 양성을 위한 교육 혁신 프로그램」 워크숍 발표 자료와 함께 공개합니다.

- `index.html` — 처음: 두 워크플로, 센 값, 역할(AI · 코드 · 교수), 구글 버전과의 비교
- `deck.html` — 워크플로 1: 강의 덱 — 교안에서 JNUclass까지 (9단계)
- `grading.html` — 워크플로 2: 과제 평가 — 게시에서 확정까지 (9단계) + 가상 피드백 예시(인용 대조 · 수정본 복원을 브라우저에서 직접 실행)

## 넣지 않은 것
- 학생 이름 · 학번 · 제출물 · 얼굴 · 목소리. 피드백 예시의 학생 글은 이 사이트를 위해 지어낸 것입니다.
- 교재 본문 · 교사용 지도서 원문 · 교재 음원.
- 계정 정보와 API 키.
