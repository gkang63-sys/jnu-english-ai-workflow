# deck-kit

제주대 교양영어 이중언어 강의 덱 키트 (제미나이 Gem판).

덱 HTML 맨 끝에 아래 한 줄을 두면 디자인·연습 채점·학생 모드·낭독·듣기 바·영상·자동 강의·한 파일 내보내기가 모두 동작한다.

```html
<script src="https://cdn.jsdelivr.net/gh/gkang63-sys/jnu-english-ai-workflow@deck-kit-v1/deck-kit/deck-kit.js"></script>
```

버전을 바꿀 때는 새 태그(deck-kit-v2 …)를 만들고 덱의 주소도 그 태그로 바꾼다. 이미 만든 덱은 옛 태그를 계속 쓰므로 깨지지 않는다.
